# Sujit Prasad Portfolio

This repository contains only the public portfolio website. It does not include former-employer code, client data, credentials, or private project artifacts.

## Local preview

```bash
pnpm install
pnpm dev
```

## Deployment

Push the `main` branch to the `sujitprasad-data.github.io` repository. GitHub Actions creates the static site and deploys it to GitHub Pages at `https://sujitprasad-data.github.io`.
